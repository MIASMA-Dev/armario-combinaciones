# Prompts de esquemático (wireframe / comp) por mundo visual

Usa estos prompts para generar imágenes del **esquemático de pantalla** (layout + jerarquía) de la app Armario. Estilo: wireframe de alta fidelidad o comp de producto, no asset aislado.

## Plantilla base (común a todos)

"Product UI screen for 'Armario y Combinaciones': inventory of garments with columns (name, color, season, state), filter bar, tabs for Inventario/Outfits/Ordenes, primary action 'Capturar prenda', realistic sample data, first viewport only, clean grid, clear hierarchy, no placeholder tiles."

## 1. Variable Font Specimen

"A high-fidelity product screen for an armario app in the Variable Font Specimen world: near-white paper ground, ink black text, one foundry accent; a single oversized glyph as signature in the header; inventory table in a strict baseline grid; monospace coordinate readout for counts; flat, generous negative space, no ornament. Include tabs, filters, and realistic garment data."

## 2. Pop Culture Shelf — Character Goods Catalog

"A high-fidelity product screen for an armario app in the Pop Culture Shelf world: soft pastel ground, white keyline cards, rounded mascots as garment thumbnails, name plates with 'birthday' as capture date, one saturated ribbon color per state; grid of garment cards ranked by use, flat fills, friendly labels. Include filters and a bottom action bar."

## 3. Digital Design Canon — Warm Consumer App Surface

"A high-fidelity product screen for an armario app in the Warm Consumer App world: warm tinted ground, white soft-cornered cards, one saturated action color only on actionable elements, plain-language labels, cards holding one idea each, persistent bottom bar for navigation, soft spring on press (static in image). Inventory as card list with state chips. Include filters and empty-state card."

## 4. RW Timetable — Slide Rack

"A high-fidelity product screen for an armario app in the Slide Rack world: goldenrod bed under slate tinted glass, carbon ink, one single type size with hierarchy by weight/case, rake-angled containers, tick rail for position, state as filled/hollow marks, vermilion for errors, green for confirmations. Inventory as ruled columns, tabs as slides. Include filters."

## 5. Manual Acetate Tab Board (asignado)

"A high-fidelity product screen for an armario app in the Acetate Tab Board world: milk-acetate reading surface over an oxide-orange section board, punched holes along bound edge, stepped tab rail down the fore edge (Inventario/Outfits/Ordenes), Univers headings in fifth margin column, Sabon body at 62-char measure, state as punched hole (selected), face-down (disabled), half-hinged (pending), vermilion errata slip (error). Inventory table on acetate. Include filters."

## 6. Vernacular Ephemera — Jet-Age Ticket Wallet

"A high-fidelity product screen for an armario app in the Ticket Wallet world: carrier navy and red over crisp white coupon stock, carbon purple numerals, hairline-ruled boxes, tabs as coupon stubs, states stamped (validated/used/void), route-map arc as signature in header. Inventory as coupon book with one garment per stub. Include filters."
